# Downloads

Official Air Inter VA software releases, including Hermès ACARS, are published through GitHub Releases:

- [Download the latest Hermès release](https://github.com/BragaAteMorrer/airinter-va-project/releases/latest)
- [Browse all releases](https://github.com/BragaAteMorrer/airinter-va-project/releases)

## Code signing

This project uses **SignPath Foundation** for free code signing of eligible open-source release artifacts.

Code signing is provided through **SignPath.io / SignPath Foundation**. Signed release artifacts are built from this public repository using GitHub Actions and submitted to SignPath for signing according to the project's [Code signing policy](./CODE_SIGNING_POLICY.md).

The project's privacy policy is available in [PRIVACY.md](./PRIVACY.md).
