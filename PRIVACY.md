# Privacy policy

## Scope

This policy covers the public Air Inter VA software repository and its release/signing process, including Hermès ACARS, Prométhée and Argos.

## Repository and release data

The project itself does not intentionally collect personal information merely because someone browses, clones or builds the public repository.

GitHub and SignPath may process account, repository, build, audit and signing metadata according to their own services and privacy policies when contributors or maintainers use those platforms.

## Hermès and connected services

Hermès may exchange the minimum account, authentication, flight-operation and telemetry information required to provide its ACARS functions with Air Inter VA services such as Argos and Prométhée.

The project does not sell personal data.

Authentication secrets, private signing keys and production credentials must not be committed to this repository.

## Code signing

For releases signed through SignPath Foundation, unsigned release artifacts and associated build/provenance metadata may be submitted to SignPath for verification and signing. Signing keys remain managed by the signing provider and are not distributed with the source repository.

## Security and retention

Project maintainers should avoid retaining personal information longer than necessary for the relevant operational or security purpose.

Security issues or accidental exposure of personal information should be reported privately as described in [SECURITY.md](./SECURITY.md).

## Contact

Privacy questions relating to this project should be directed to the Air Inter Virtual Airlines project maintainers through the project's established contact channels.
